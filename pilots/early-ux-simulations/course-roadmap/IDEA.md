# Complex Live Pilot Idea — First Public Course Release

Use Portable Planner to create a real, end-to-end plan that takes Drew's AI course from its current state to a cohesive first public release for total beginners.

## Current reality to treat as input

- Module 1 is assembled and waiting for Drew's signed-in student-page review.
- Module 2 is in early planning.
- Module 3's planning method is being productized through Portable Planner.
- Module 0 is deferred until the larger roadmap is stable.
- `drewpullen.com` is the one public front door.
- The course-delivery surface is LearnHouse; it is not a second public funnel.
- Lessons must be action-first, hand-hold every click, use browser or normal desktop installation in the core path, and state accounts, costs, waiting, and failure points.
- Production must be demonstrated from a clean slate rather than Drew's configured environment.

## Planning destination

Produce a visual, execution-ready course-system plan that covers the complete route from today's partially assembled material through curriculum decisions, lesson production, clean-slate verification, LearnHouse delivery, the public front door, release proof, and the first useful feedback loop.

The planning conversation must determine what the first public release actually promises and contains. It must not silently assume the old Module 0-first direction, invent a second website, implement course work, or ask Drew to choose internal architecture and tooling the agent can derive.

## Why this is the complex pilot

This is a real course and business system with multiple repositories, human creative decisions, production dependencies, student-experience constraints, release proof, and post-release learning. It is intentionally more complex than the trusted-channel comment finder while remaining a plan Drew may genuinely use.
