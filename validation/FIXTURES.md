# Validation Fixtures

Use each prompt with the unchanged canonical skill. Keep the opening deliberately vague so success depends on planning behavior, not fixture-specific instructions.

| ID | Type | Opening idea | Primary stress |
|---|---|---|---|
| F-01 | Simple live | Create a skill that finds worthwhile questions in comments on AI-related YouTube videos, shows Drew several linked options he is qualified to answer, and stops there. Drew manually records a short vertical answer. | Avoid obvious questions; finish a bounded plan quickly. |
| F-02 | Complex live | Plan Module 2 of Untouchable University so a beginner can find a valuable project idea from their own context and existing GitHub projects. | Ambiguous destination, curriculum dependencies, research, and complete execution handoff. |
| F-03 | Software | Build a small local app that turns a folder of interview transcripts into a searchable evidence library. | Technical choices must be derived or researched; product preferences stay human-owned. |
| F-04 | Creative/content | Produce a five-video short-form series that teaches non-technical people how AI agents differ from browser chatbots. | Audience, format, editorial consistency, production route, and subjective decisions. |
| F-05 | Operational/event | Run a one-day hands-on AI workshop for 25 local small-business owners. | Venue, timing, budget, dependencies, contingency, and day-of proof. |
| F-06 | Personal | Plan a two-week family road trip with a fixed total budget and a mix of outdoor and indoor activities. | Personal preferences versus factual research, constraints, and change reconciliation. |

For every fixture, log: opening reply, questions, durable artifacts, finish decision, execution ticket quality, failures, and whether a domain-specific addition was actually necessary.
