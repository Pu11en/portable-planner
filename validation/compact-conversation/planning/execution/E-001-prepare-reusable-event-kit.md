# E-001 — Prepare the Reusable Event Kit

- Outcome: One reusable, no-budget host kit is ready for each monthly skill-share.
- Depends on: P-001

## Context

- [Confirmed participation experience](../decisions/P-001-define-participation-experience.md)

## In scope

- Create a one-page host run sheet with the confirmed 90-minute agenda.
- Create invitation and sign-up copy that lets each person offer a 20-minute skill or attend as a learner.
- Create a short teacher prompt covering the practical outcome, required participant materials, capacity, room fit, and pass/observe option.
- Create a station-and-group assignment sheet, arrival prompt, and room-reset checklist.
- Create a response check that identifies first-time attendees and asks whether they felt comfortable joining in and whether they would return.

## Out of scope

- Reserving the room, recruiting attendees, choosing teachers, buying supplies, or running an event.

## Constraints

- The kit must preserve the free room, no-budget boundary, participant-supplied materials, guided small groups, and absence of networking activities.
- The response check must be quick enough to complete during the 10-minute closing.

## Proof

- The kit contains the agenda, invitation, role sign-up, teacher prompt, assignments, arrival prompt, reset checklist, and the three required response fields with no unresolved placeholders.

## If blocked or disproven

- Return to planning only if the confirmed format cannot fit 90 minutes or requires organizer spending; otherwise simplify the kit within the confirmed decision.

## Human review

- The host confirms the language is welcoming, usable in the library, and easy to repeat monthly.
