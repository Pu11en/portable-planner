# E-003 — Build the Room and Show Operations Package

- Outcome: One usable indoor runbook covers layout, AV, accessibility, staffing, check-in, show control, cleanup, and measurement.
- Owner: Agent prepares and verifies the package with the venue manager and named human event lead.
- Depends on: E-001, E-002

## Context

- [Venue confirmation](E-001-confirm-indoor-venue.md)
- [License and budget](E-002-license-movie-and-budget.md)
- [Direct indoor requirements](../evidence/P-002-evidence.md)

## In scope

- Create a room layout for about 80 attendees that keeps the marked center aisle and both exits unobstructed and identifies accessible entrances and restrooms.
- Define attendee-supplied blanket/chair placement, check-in flow, maximum-capacity control, and late-arrival handling.
- Test the built-in projector and sound with the licensed playback source and document inputs, controls, visibility, audibility, and a non-equipment-rental failure response.
- Assign setup, door/check-in, safety, playback, cleanup, and attendance-measurement responsibilities.
- Define counts for total attendance and attendance remaining when credits begin, plus incident, rule-compliance, spend, and cleanup records.

## Out of scope

- Advertising, outdoor work, buying backup AV, changing the movie, and running the event.

## Constraints

- Never block the center aisle or either exit.
- Do not exceed the posted capacity of 100 or the $400 total cap.
- Use the built-in projector and sound unless a direct test disproves adequacy and returns the plan for revision.

## Proof

- A venue-confirmed layout, successful documented AV test, named responsibility list, timed run-of-show, cleanup checklist, and outcome-measurement form exist and agree with the venue and license terms.

## If blocked or disproven

- Return to planning if safe seating for the target audience cannot coexist with the aisle and exits, or if built-in AV cannot support the licensed show without exceeding the budget.

## Human review

- The venue manager confirms the layout; the human event lead accepts all named physical responsibilities.
