# Plan: Searchable interview evidence library

## Destination

A small local app that turns interview transcripts into a library where the intended user can find and reopen source-backed evidence.

## Success

- The intended user can add interview transcripts, search for relevant evidence, and trace each result back to its source transcript.

- In: The first user, core evidence-finding workflow, local-app scope, and objective proof of usefulness.
