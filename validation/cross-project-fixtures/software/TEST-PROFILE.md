# Synthetic decision profile

- User priority: find trustworthy source passages quickly, not generate polished reports.
- Privacy: transcripts must remain on the user's machine.
- Input: ordinary text and Markdown transcripts in one selected folder.
- Scale: up to 500 transcripts for the MVP.
- User comfort: normal desktop UI; no terminal in the everyday path.
- Test behavior: whenever a genuine preference remains after applying this profile, record the exact question and options, then select the planner's recommended A option.
