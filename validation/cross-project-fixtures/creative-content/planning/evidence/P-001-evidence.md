# P-001 Evidence — Agent, Chatbot, and Review Claims

Accessed: 2026-08-05

## Source 1

- Source: [OpenAI — A practical guide to building agents](https://openai.com/business/guides-and-resources/a-practical-guide-to-building-ai-agents/)
- Relevant finding: The guide distinguishes an agent from a simple chatbot by whether the language model manages execution of a multi-step workflow. It describes agents as using tools to gather context or take actions within guardrails, and recommends human intervention for failure thresholds and high-risk actions.
- Decision changed: Episodes 1 and 2 teach response versus workflow control—not browser window versus another interface—and describe tools as access, not magic. Episode 5 makes review an operating checkpoint rather than a disclaimer.

## Source 2

- Source: [Anthropic — Trustworthy agents in practice](https://www.anthropic.com/research/trustworthy-agents)
- Relevant finding: Anthropic describes the practical agent loop as planning, acting, observing, and adjusting until completion or a need for human input. It also identifies tools, instructions/guardrails, permissions, and human control as core parts of safe operation.
- Decision changed: Episode 2 uses the plain-language “plan → act → check → adjust or stop” loop. Episode 5 requires human approval before the example sends anything.

## Source 3

- Source: [OpenAI — Workspace agents for business](https://openai.com/business/workspace-agents/)
- Relevant finding: The page gives recurring lead review and outreach as agent workflows, describes gathering information and taking action across tools, and presents permissions, monitoring, and approval gates as controls.
- Decision changed: Episode 4 uses recurring lead-follow-up preparation as the shared small-business example, while stopping at a review queue rather than sending messages.

## Research stop

The three direct sources agree on the claims that materially shape this short series: workflow control, tool use, an iterative loop, and explicit oversight. More sources would add terminology but would not change the five-part route.
