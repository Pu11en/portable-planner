# E-002 — Build the Recording Pack

- Outcome: A complete, rehearsed production pack that makes all five videos recordable with the presenter, phone camera, and screen recorder.
- Depends on: P-001, E-001

## Context

- [Series route and guardrails](../decisions/P-001-lock-series-route.md)
- E-001's approved script set

## In scope

- Create a five-video shot manifest with presenter framing, screen inserts, overlay text, and file names.
- Create only the fabricated lead names, enquiry snippets, urgency labels, draft replies, and review-queue screens explicitly required by the scripts.
- Prepare a simple 9:16 composition guide and a capture checklist for clean audio, stable framing, readable screen crops, and uncluttered background.
- Rehearse each script once with its visual cues and record the measured runtime.
- Revise cue timing or on-screen density without changing the approved teaching claims.

## Out of scope

- Live CRM or email access, real customer data, paid stock assets, custom animation, recording final takes, editing, publishing, or script-route changes.

## Constraints

- Every name, message, business detail, and account shown on screen is fabricated.
- Screen text must be legible in a vertical mobile frame and support the speaker rather than repeat every word.
- The pack must support one recording session and one later editing session.

## Proof

- The pack contains a shot manifest, asset list, fabricated demo data, named screen states, composition guide, capture checklist, and measured rehearsal runtimes for all five videos.
- No item requires equipment or access beyond the confirmed resources.
- A dry run can follow the pack from video 1 through video 5 without an unresolved shot, asset, or live-system dependency.

## If blocked or disproven

- Return to E-001 for a bounded script/cue simplification if a video cannot rehearse below 55 seconds or its screen example is unreadable; return to P-001 only if preserving the episode's job would require a new resource or live integration.

## Human review

- The presenter confirms the teleprompter/script view, framing, cue order, and complete recording run are practical in one session.
