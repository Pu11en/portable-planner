# E-001 — Write the Five Scripts

- Outcome: A review-ready script set for all five videos, with timed spoken copy and exact on-screen cues.
- Depends on: P-001

## Context

- [Series route and guardrails](../decisions/P-001-lock-series-route.md)
- [Factual evidence](../evidence/P-001-evidence.md)

## In scope

- Write five individually labeled scripts in route order.
- Give each script one hook, one teaching beat, one concrete example or continuation of the lead-follow-up example, and one takeaway.
- Include the exact on-screen text and screen-action cue beside the relevant spoken line.
- Target 110–135 spoken words per video, then read aloud and revise until every script times below 55 seconds to preserve edit margin.
- Add a claim check that maps every factual claim to P-001 evidence or marks it as a clearly framed example.

## Out of scope

- Recording, asset creation, editing, publishing copy, platform-specific calls to action, new episodes, live product demonstrations, or changing the confirmed route.

## Constraints

- Friendly, concrete, non-technical voice; no hype, fear, jargon dependence, or vendor-specific capability promise.
- Preserve the five episode jobs and the single “reply to reviewed workflow” progression.
- Never imply that agents are always preferable, error-free, or safe without permissions and review.

## Proof

- One document contains exactly five complete scripts in order.
- Each read-aloud timing is recorded and is below 55 seconds.
- Every script has spoken copy, on-screen copy, one visual cue, and a claim-check line.
- Together the scripts contain every success element listed in `PLAN.md`.

## If blocked or disproven

- Return to P-001 if accurate wording cannot preserve the confirmed episode job, if any script requires a live-system capability claim, or if the five-part route cannot meet the outcome under the runtime limit.

## Human review

- The presenter reads all five aloud and confirms that the language is natural to say, understandable without technical background, and faithful to the approved route.
