# E-003 — Capture the Footage

- Outcome: Organized, usable presenter and screen-recording takes for all five approved scripts.
- Depends on: P-001, E-002

## Context

- [Series route and guardrails](../decisions/P-001-lock-series-route.md)
- E-001's approved scripts
- E-002's recording pack and capture checklist

## In scope

- Capture the presenter in vertical framing for all five scripts.
- Capture the screen actions named in the manifest using only the fabricated demo assets.
- Record a pickup immediately for a factual stumble, clipped audio, missed cue, or unusable delivery.
- Name and organize source files by video number, media type, and take.
- Select one preferred presenter take and the required screen take for each video.

## Out of scope

- Script rewrites beyond a word-level correction, live business accounts, real customer information, extra episodes, custom B-roll, editing, color work, captions, publishing, or audience testing.

## Constraints

- Use only the confirmed presenter, phone camera, screen recorder, and prepared assets.
- Do not capture notifications, credentials, personal data, or unrelated desktop content.
- Preserve enough pause around each line and screen action for clean edits.

## Proof

- All five video folders contain a selected presenter take and every required screen insert.
- The capture checklist passes for intelligible audio, stable vertical framing, complete lines, readable screen footage, and absence of sensitive or real customer data.
- Every source file opens and matches its manifest label before the session ends.

## If blocked or disproven

- Repeat only the affected take for capture defects; return to E-002 if a prepared shot is technically unreadable; return to P-001 if the approved episode cannot be captured with the confirmed resources.

## Human review

- The presenter approves the selected takes for factual accuracy, natural delivery, and acceptable appearance before the recording setup is cleared.

- E-004 — Edit the five videos.
