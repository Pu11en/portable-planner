# Synthetic decision profile

- Audience: curious small-business owners who use browser chat but have never used an agent.
- Outcome: viewers should recognize one task that benefits from an agent and understand the need for review.
- Voice: friendly, concrete, and non-technical; no hype or fear.
- Format: vertical talking-head videos with simple on-screen examples, under 60 seconds each.
- Resources: one presenter, phone camera, screen recording, and one editing session.
- Test behavior: whenever a genuine preference remains after applying this profile, record the exact question and options, then select the planner's recommended A option.
