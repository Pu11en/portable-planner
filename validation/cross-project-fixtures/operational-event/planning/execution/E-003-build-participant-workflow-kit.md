# E-003 — Build Participant Workflow Kit

- Outcome: Deliver a tested beginner-facing kit that lets an attendee build, run twice, review, and retain one safe AI-assisted workflow.
- Depends on: P-001, E-002

## Context

- [P-001 operating model](../decisions/P-001-workshop-operating-model.md)
- Confirmed venue capabilities and E-001 approved-service findings.

## In scope

- Create the plain-language workbook, workflow-selection examples, workflow card, synthetic sample-data pack, prompt/step templates, review rubric, safety card, prerequisites, and access-check instructions.
- Provide a tested recovery path for login failure, weak connectivity, and attendees who need extra guidance without using confidential data.
- Walk the complete kit on a clean device and correct every blocking ambiguity.

## Out of scope

- Custom software, attendee-specific consulting, legal/professional assurance, facilitator staffing, registration, or public promotion.

## Constraints

- Use only approved services and synthetic, redacted, or public examples.
- A pass requires two successful runs, a named human check, facilitator review, and a next real-business use.

## Proof

- Versioned participant files plus a clean-device test log showing one novice path from prerequisite check through two runs, review correction if needed, and exported workflow card.

## If blocked or disproven

- Correct the materials; if the approved service or fallback cannot meet the result safely, return to planning. E-004 remains ineligible.

## Human review

- Drew reviews instructional accuracy, tone, business relevance, and the safety language using the full novice path.
